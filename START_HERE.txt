PDSA + TECHFORM CANYON — VS CODE AGENT HANDOFF
================================================

1) Open THIS FOLDER in Visual Studio Code.
2) Read README.md. To view the working purple board demo,
   open index.html in any browser (or use: npm run dev).
3) Open AGENTS.md, AGENT_HANDOFF.md and docs/PAYMENTS_AND_CUTOVER.md.
   Copy the prompt from docs/AGENT_START_PROMPT.md into

feeding evaluation scoring/CSV, provisional team balance, staff/volunteer/ref
tracking, team-restricted coach view, targeted demo outbox, Techform-to-PDSA
